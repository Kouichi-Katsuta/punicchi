# キャラクター画像（React 版用）

このフォルダに PNG を置くと、キャラがその画像で表示されます（育成画面・タイトル・進化・ずかん）。置かなければ `Pet.jsx` の SVG で描きます。

- ファイル名：`形態キー.png`（ふつう） / `形態キー_sad.png`（困り顔） / `形態キー_sleep.png`（ねている）
- 形態キー：`egg` / `baby` / `childG` / `childB` / `adultS` / `adultG` / `adultB`
- 推奨サイズ 390×390 px、背景透過
- バニラ版は `assets/pets/` に同じファイルを置く。詳しくはリポジトリ直下の `SPEC.md`
