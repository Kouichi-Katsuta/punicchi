# キャラクター画像（バニラ版 `index.html` 用）

このフォルダに PNG を置くと、キャラがその画像で表示されます。置かなければ今までどおり SVG で描きます。

| ファイル名 | いつ使う |
|---|---|
| `形態キー.png` | ふつうのとき（表情別の画像がないときもこれを使う） |
| `形態キー_sad.png` | 困り顔（どれかのステータスが 25 未満） |
| `形態キー_sleep.png` | ねているとき |

形態キー：`egg` / `baby` / `childG` / `childB` / `adultS` / `adultG` / `adultB`（たまごは `egg.png` だけ）

- 推奨サイズ 390×390 px、背景透過。画像の下端がキャラの足もとになる
- React 版は `react-app/public/pets/` に同じファイルを置く
- 詳しくは `SPEC.md` の「9. 画像素材の差し替えリスト」
